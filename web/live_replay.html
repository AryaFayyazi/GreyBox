Grey Box Live: a recorded session

Qwen3-8B served behind an API. Before each reply, 24 yes/no questions went to copies of the conversation; the real reply never saw them. Because this model is open, its true hidden state is shown next to the estimate.

Conversation
Every point in the cloud is an open model answering the same 24 questions about one message. The space is shared by all models. Copper: this conversation, turn by turn.

Hidden state: estimated vs true
Known limitation, shown on purpose. The readouts were trained and checked on single messages. In a multi-turn chat the questions also see earlier turns, so an alarm can carry over: the arithmetic turn right after the poison request is flagged although the model just answered “391”. The next version trains on multi-turn conversations to remove this.
