# Grey-box theory: what black-box access can and cannot recover for safety forecasting

Status: draft statements with proofs. Classical results marked [U] are cited from memory and must be verified
before the paper uses them.

## Notation

- B: the agent (a language model with a fixed sampling rule). E: the environment kernel (tool results given actions).
- x: the full context at the start of an agent turn (system prompt, task, earlier actions and tool results).
- τ: the future trajectory generated by B and E from x. P_{B,E}(τ | x) is its law.
- Y = g(τ) ∈ {0,1}: a behaviour-defined safety label (e.g. "the action of this turn is unauthorized",
  "the agent later misreports").
- φ(x) ∈ R^D: any internal representation computed from x and the weights (a residual-stream vector, a set of
  layers, the whole KV cache). A white-box monitor is a score f(φ(x)).
- π*(x) = P_{B,E}(Y = 1 | x): the behavioural forecast.

**Assumption A1 (no hidden future randomness).** Given x, the internal representation carries no information about
the sampling noise that will generate τ: τ ⟂ φ(x) | x. This holds whenever φ(x) is a deterministic function of x and
the weights, which is the case for every white-box probe in the literature (batch-level numerical nondeterminism is
independent of the future sampling noise).

## T1. Behavioural sufficiency: probes cannot beat rollouts

**Proposition 1.** Under A1, for every measurable f:
1. (Proper scores.) For every strictly proper scoring rule S, E[S(π*(X), Y)] ≥ E[S(f(φ(X)), Y)].
2. (ROC dominance.) The ROC curve of π*(X) lies on or above the ROC curve of f(φ(X)) at every false-positive
   rate. In particular AUROC(π*) ≥ AUROC(f∘φ).
3. (Within strata.) Both statements hold within any stratum s(X) that is a function of X. Hence they hold for the
   pair-weighted within-stratum AUROC used by CAPE.

*Proof.* (1) By A1 and the tower property, E[Y | φ(X)] = E[π*(X) | φ(X)]. The Bayes act under a strictly proper rule
given information σ(X) is π*(X). Since σ(φ(X)) ⊆ σ(X), conditioning on less information cannot raise the expected
score. (2) By Neyman–Pearson, among all tests based on X at a fixed false-positive rate, the most powerful test
thresholds the likelihood ratio Λ(x) = p(x | Y=1)/p(x | Y=0). By Bayes' rule, Λ(x) is a strictly increasing function
of π*(x). Any test based on f(φ(X)) is a test based on X. So the ROC of π* dominates pointwise. (3) Apply (1) and
(2) to the conditional law given s(X) = s. A weighted average of dominated per-stratum AUROCs with the same weights
is dominated. ∎

**Proposition 2 (finite rollouts).** Let π̂_K(x) be the fraction of K independent rollouts from x with Y = 1. For a
positive-negative pair (x⁺, x⁻) with Δ = π*(x⁺) − π*(x⁻) > 0, Hoeffding's inequality on the K paired differences
(each in [−1, 1]) gives P(π̂_K(x⁺) ≤ π̂_K(x⁻)) ≤ exp(−KΔ²/2). So
AUROC(π̂_K) ≥ AUROC(π*) − E_pairs[exp(−K Δ²/2) · 1{Δ > 0}], up to the tie convention. ∎

**Corollary 1 (irreducible ceiling).** Because Y is a single draw, AUROC(π*) < 1 whenever behaviour is stochastic.
No monitor of any kind, white-box or black-box, can exceed AUROC(π*). The ceiling is measurable from rollouts.
This gives each monitor m a relative efficiency (AUROC(m) − ½) / (AUROC(π*) − ½).

**Corollary 2 (one-step labels need one query).** If Y depends only on the next token (Y = 1 iff the next token lies in
a set A), then π*(x) = Σ_{a∈A} p(a | x). A logprob API returns this exactly in one call when A is covered by the
returned top-k. No hidden-state probe can then beat a single black-box query. *Observed (Othello-GPT, label "the next
move is a corner"):* the one-query forecast scores AUROC 0.877, at the K=64 rollout ceiling (0.872). A trained
white-box probe on the layer-6 state scores 0.744. Across horizons H = 1, 3, 6 the probe is worth about 5–6 rollouts
(results/othello/t1_othello*.json).

**What T1 does not say.**
- It does not make rollouts cheap. A rollout costs K samples of the future. For labels that lie several turns
  ahead, it also needs the environment E, which a deployed monitor usually cannot simulate. White-box readouts and
  the interrogation state are cheap approximations to π*. The empirical question is how close each comes, at what
  cost.
- It does not apply to labels not defined by behaviour (for example "the model believes p"). For those, internals
  may carry information that no behaviour reveals. CAPE's labels (violation, misreport) are behavioural.
- **Unit selection.** If units are selected using events after x (for example "other turns of episodes that never
  violate"), the conditional law of Y given x and selection can differ from π*. The confirmatory design therefore
  defines units by information available at x, or reports the selection.

## T6. Access is not information: what a white-box monitor can add to a transcript monitor

**Setup.** A monitor acts at step t of an episode, after the agent has proposed an action and before it executes.
- Z_t: every token the agent has read or written so far: instructions, task, tool results, and its own outputs,
  including reasoning tokens.
- V_t: the part of Z_t a deployment can see. H_t: the rest (e.g. reasoning that the API hides), so Z_t = (V_t, H_t).
- A_t: the proposed action (tool and arguments), part of the agent's output and visible to a monitor that intercepts
  tool calls.
- W: facts about the world that the agent has not observed.
- φ_t = Φ(Z_t; θ): any internal representation of the agent at step t (residual stream, KV cache, logits). It is a
  deterministic function of the tokens it read (A1; batch-level numerical noise aside).
- The label Y is behavioural.

**Proposition 10 (access is not information).** For every label Y, σ(Z_t, φ_t) = σ(Z_t). Hence:
1. The Bayes-optimal monitor using (Z_t, φ_t) is no better, under any proper score or at any point of the ROC, than
   the Bayes-optimal monitor using Z_t (Proposition 1, applied to Z_t).
2. **The information gap.** Under log loss, the best white-box monitor at step t beats the best transcript monitor by
   exactly H(Y | V_t) − H(Y | Z_t) = I(Y; H_t | V_t), the information about Y in the hidden tokens alone. If the API
   exposes all tokens (H_t empty), the gap is 0.

*Proof.* φ_t is σ(Z_t)-measurable, so adding it to Z_t adds no events. (1) follows from Proposition 1 with X = Z_t.
(2): the Bayes log-loss of predicting Y from a σ-field G is H(Y | G). The difference of the two conditional entropies
is the conditional mutual information. ∎

**Corollary 3 (action-level labels: the proposed action is sufficient).** Suppose Y = g(A_t, V_t, W), where g is
the policy check for the action given the visible facts, and W is independent of the agent's tokens given what it
has seen: W ⟂ Z_t | V_t. Then for a monitor that reads (V_t, A_t), the gap to every white-box monitor at or before
the decision point is zero: P(Y | V_t, A_t, H_t, φ_t) = P(Y | V_t, A_t).
- The internals cannot add information about W, because the agent learns about W only through tool results, which
  are in V_t.
- Given the action, the hidden reasoning that produced it is irrelevant to Y.
- A white-box probe read just before the action is emitted must, in addition, predict which action will be sampled.
  Its Bayes risk is therefore at least that of the transcript-and-action monitor, and can be strictly larger when the
  agent's action is random given its internals and the label depends on which action is taken.

*Proof.* Write Z⁻ for the agent's tokens before the action is sampled, so V_t and H_t are functions of Z⁻ and
A_t = a(Z⁻, ξ), with sampling noise ξ independent of (Z⁻, W).
- From W ⟂ Z⁻ | V_t and ξ ⟂ (Z⁻, W): W ⟂ (Z⁻, ξ) | V_t, hence W ⟂ (Z⁻, A_t) | V_t (A_t is a function of Z⁻ and ξ),
  hence by weak union W ⟂ Z⁻ | (V_t, A_t). As Y = g(A_t, V_t, W), Y ⟂ Z⁻ | (V_t, A_t), so
  P(Y | Z⁻, A_t) = P(Y | V_t, A_t). Every internal representation is a function of Z⁻
  (and of A_t once it is written), which proves the first claim.
- A white-box monitor at the decision point uses some φ = Φ(Z⁻). Its information σ(φ) ⊆ σ(Z⁻) ⊆ σ(Z⁻, A_t). The
  Bayes predictor given σ(Z⁻, A_t) equals the one given (V_t, A_t) by the first step. By Proposition 1 (less
  information cannot help), its Bayes risk is at least that of the (V_t, A_t) monitor. The inequality can be strict
  when A_t is random given Z⁻ and Y depends on A_t. ∎

**Relation to identifiability of representations.** Zhou and Klindt (2026, arXiv 2610.20851) show that latents made
identifiable by supervised training are recovered by encoders that are linear in them when the representation is
complete, and only through sparsity (compressed sensing) when it is undercomplete. Proposition 4 (gauge) is the
output-side counterpart: from outputs alone, hidden coordinates are identified only up to the function-preserving
group. T15's linear map between two models that read the same tokens follows the complete case. A check of the
undercomplete case (a nonlinear map) is exploratory (scripts/88c): a one-hidden-layer MLP replicates less than the
linear map (R² 0.558 vs 0.664), so the data give no sign that the linear replica is limited by the map.

**What remains is statistics.** For a trained transcript monitor m, the excess log loss over the best white-box
monitor at the decision point is:

    I(Y; H_t | V_t, A_t)                  (information gap: 0 under Corollary 3)
  + [L(m) − H(Y | V_t, A_t)]               (learning the policy check g from data)

The second term is the usual excess risk of learning P(Y | V_t, A_t). It is driven by:
- the label function used for training or scoring (the environment's checker vs an LLM judge);
- the number of labelled examples and their coverage of the policies g enforces;
- the representation (bag of words vs a reader model) under distribution shift.

**Predictions, and the tests that check them.**
- **T2 (information gap before the action):** at the turn start, before the action exists, internals trail
  resampling. After the reasoning, I_dec reaches 0.979: reading later closes most of the gap.
- **T4, T5 (Corollary 3):** a reader of (V_t, A_t) trained on the same labels matches or beats the agent's internals
  read just before the action (0.994 vs 0.979; 0.969 vs 0.976 on unseen families).
- **Corollary 3 directly (exploratory; scripts/69b):** adding the agent's hidden reasoning H_t to the reader's input,
  given the action, changes AUROC by −0.0014 [−0.0046, +0.0014]. That is I(Y; H_t | V_t, A_t) ≈ 0, as predicted.
- **T3 (label function):** with an LLM judge in place of g, judge-scored resampling falls below the probe (0.782).
  The bottleneck is the label function.
- **T9, T10 (estimation and coverage):** a bag-of-words learner matches the reader in distribution and fails under
  shift. For a policy family absent from training, violations are ranked but not escalated until about 20–40 labels
  of it are added.

**Limits.**
- Corollary 3 needs the label to be decidable from the action and the visible facts. Labels about later behaviour
  (a misreport two turns ahead) or about beliefs are not covered; for behavioural ones Proposition 1 applies.
- It assumes that the deployment sees the proposed action before it executes.
- It is a statement about Bayes-optimal monitors. Finite-sample learners can still differ, which is what T4–T10
  measure.

## T2. Interrogation state and its sufficiency

For a battery Q = {q_1, …, q_m} of suffix questions with one-token answers, the interrogation state is
Ψ_Q(x) = (P_B(Yes | x ⊕ q_j))_j. One query per item returns it (logprob tier), or n samples estimate it (text-only
tier).

**Proposition 3 (linear sufficiency under finite rank) [classical PSR result, U].** Suppose the system dynamical
matrix of B (rows: contexts; columns: tests, i.e. suffix-answer events, including continuations of the agent's own
turn) has finite rank r. Then there are r core tests whose probabilities determine every test probability linearly.
If Q contains a set of core tests, every π*(x) for an event that is a test is a linear function of Ψ_Q(x).
Real transformers need not have finite rank. The finite-rank model is a working hypothesis. We measure it by the
singular-value spectrum of the matrix of Ψ̂ over many contexts, and by how forecast quality saturates in m.

**Why the battery reads state rather than self-report.** The answer to q_j is a behaviour of B at the forked
context x ⊕ q_j. Its probability is a deterministic function of x, so Ψ_Q is an observation of the state. It does not
need to be truthful to be informative. Unrelated questions (lie-detector style) read the state through answer
shifts. Self-report items are one subset, and their contribution is measured by ablation.

## T3. Gauge: why hidden coordinates cannot be the shared target, and Ψ can

**Proposition 4 [Carlini et al. 2024, Lemma 4.2; report §2].** Even with exact full-vocabulary logprobs, the final
hidden state is identified only up to an unknown invertible matrix G ∈ GL(d), and intermediate layers leave no
footprint in the outputs.
**Consequence.** A white-box probe direction w fitted on model A has no defined meaning on a black box C. Matching it
needs paired hidden states, which a black box does not provide.
**Proposition 5 (Ψ is gauge-free).** Ψ_Q(x) is a vector of probabilities of fixed events, so it is identified exactly
and its coordinates mean the same for every model. A forecaster fitted on Ψ_Q from open models applies to any black
box without alignment. Its only failure mode is distribution shift between models, which leave-one-family-out tests
measure directly.

## T4. Estimation and geometry

**Proposition 6 (Fisher-Rao coordinates).** For one Bernoulli coordinate with parameter p, the Fisher information is
1/(p(1−p)). The map θ = 2 arcsin √p satisfies (dθ/dp)² = 1/(p(1−p)). So θ is an isometric (Euclidean) coordinate for
the Fisher-Rao metric. For m independent questions, θ ∈ [0, π]^m with the Euclidean metric is the product Fisher-Rao
geometry. **Variance stabilization (delta method):** with n sampled answers, Var(θ̂) ≈ 1/n, independent of p. So the
text-only tier gives isotropic noise of known size, and uncertainty ellipsoids in any linear projection P are
(1/n)·PPᵀ. ∎

**Proposition 7 (cost).** With prefix caching, the logprob tier costs one prefill of x plus m short suffixes, each
with one output token. The text-only tier costs n·m one-token samples. The rollout ceiling costs K full turns. These
costs are reported per decision next to the white-box readout (one forward pass) and an LLM monitor (one long
generation).

## T2b. Exact identifiability for finite-state black boxes (Myhill–Nerode), and the depth of a battery

**Proposition 8.** Let B compute a function f: Σ* → {0,1} (output at the last position) whose behaviour is
generated by a finite automaton, with minimal automaton M (n states). Two prefixes x, x′ are behaviourally equivalent
(f(xs) = f(x′s) for all suffixes s) iff they reach the same state of M (Myhill–Nerode). Hence:
1. The minimal state δ(x) is identified exactly from black-box answers. No black-box method can identify more,
   because inequivalent internal states that never change any future output (for example the bracket balance after
   a prefix went negative) are behaviourally inert.
2. A finite battery Q identifies δ iff Q contains a distinguishing suffix for every pair of states. The suffixes up
   to length n − 1 always suffice (the classical bound). A battery whose suffixes are shorter than the depth needed to
   separate two states merges them.
3. Choosing Q to maximise the number of distinct answer patterns uses only black-box answers (no state labels), so it
   can be done on all prefixes without leakage. Greedy selection approximates a minimum distinguishing set.
*Empirical check (results/tracr/l0_dyck.json):* tracr-compiled causal shuffle-Dyck-2, 21 reachable states. A
random battery of short suffixes merges states (16 classes). The greedy black-box design picks 21 questions and
separates all 21 states. Rotating the residual stream leaves every answer identical and breaks a white-box readout
(r 0.9995 → −0.46).

## T1b. Outcome-selected units can make supervised monitors look better than the Bayes forecaster

**Proposition 9.** Let S ∈ {0,1} indicate that a turn is included in an evaluation set, and suppose S depends on
events after x. For example, negatives are taken only from episodes that never violate. Then
P(Y = 1 | x, S = 1) ≠ π*(x) in general. A classifier trained on the selected units can then exceed AUROC(π*) on them:
it learns the selection rule, not the forecast. The dominance in Proposition 1 holds only when S is a function of x
alone (the past) plus independent randomization.
*Observed:* on CAPE's decision units, which are selected by the future, TF-IDF text (0.919) beat the rollout
forecaster (0.904). Clean units (scripts/15) restore past-only selection. The confirmatory test of T1 uses them.

## T5. Hidden-state recovery (an empirical object, not a theorem)

We ask how much of the true hidden state is a linear function of θ(Ψ̂) (cross-validated R² against the top principal
components and against the white-box safety score). By T3 we do not expect raw coordinates. By T1 and T2 we expect
the *behaviourally relevant* directions to be recoverable. This is the precise sense in which the grey box
"estimates the latent space": it recovers the projection of the hidden state onto the directions that change
behaviour, in coordinates shared across models.
